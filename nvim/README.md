# neovim

**_treesitter 和 language 使用 nix安装,默认使用Mason管理,当存在IS_NIX为1时,则禁用Mason使用nix安装的_**

### Lsp

| 功能              | 快捷键        |
| ----------------- | ------------- |
| 中断输入          | \<CMD-e>      |
| 代码联想选择      | CMD-(jk/上下) |
| 查看函数/方法说明 | K             |
| 查看函数定义      | \<leader>df   |
| 查看函数大纲      | \<leader>dg   |
| 函数改名          | \<leader>rn   |
| 错误诊断          | \<leader>ca   |
| 跳转到下一个诊断  | \<leader>c[   |
| 跳转到上一个诊断  | \<leader>c]   |

### 目录导航

| 功能               | 快捷键        |
| :----------------- | :------------ |
| 打开侧边目录       | \<CMD+e>      |
| 打开当前目录       | CR/L/H        |
| 目录和文件之间跳转 | <CMD-HL/左右> |
| 竖向分屏           | \<leader>\|   |
| 横向分屏           | \<leader>\_   |

### 快捷功能

| 功能                 | 快捷键          |
| :------------------- | --------------- |
| 注释(单行多行)       | \<CMD>+/        |
| 单行或者多行上下移动 | (J/K)/(S-上/下) |
| 单行或者多行前后移动 | (H/L)/(S-前/后) |
| 当前目录搜索文件     | \<CMD-f>        |
| 当前目录搜索文件内容 | \<CMD-S-f>      |
| 函数选择             | S               |

### 窗口操作

| 功能     | 快捷键              |
| -------- | ------------------- |
| 竖向切割 | \<leader>\|         |
| 横向切割 | \<leader>\_         |
| 窗口跳转 | CMD+(HJKL/上下左右) |

### Buffeline

| 功能               | 快捷键       |
| ------------------ | ------------ |
| 关闭当前buffer     | \<CMD>-w     |
| 关闭其他buffer     | \<leader>-bo |
| bufferline左右切换 | S-(HL/左右)  |

### LazyGit

| 功能         | 快捷键      |
| :----------- | ----------- |
| 打开git      | \<leader>gg |
| 单个文件缓存 | 空格        |
| 所有文件缓存 | a           |
| 提交本次缓存 | c           |
| 提交到远程   | P           |
| 拉取远程     | p           |

### Gitsigns

| 功能               | 快捷键           |
| :----------------- | ---------------- |
| 选中代码块add      | v -> \<leader>ga |
| 选中代码块回退     | v -> \<leader>gr |
| 查看代码块变动详细 | \<leader>gp      |
| 当前文件回退       | \<leader>gr      |
